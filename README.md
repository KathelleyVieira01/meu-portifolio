## Antes de publicar
1. Substitua `SEU_EMAIL_AQUI` em `index.html` pelo e-mail profissional que deseja divulgar.
2. Troque o link `#` do LinkedIn pelo endereço correto do seu perfil.
3. Confira se a descrição do TCC representa exatamente as tecnologias e funcionalidades que você desenvolveu.
4. Adicione links para demonstrações e repositórios quando os projetos estiverem publicados.

## Publicação
Este projeto pode ser publicado gratuitamente pelo GitHub Pages. Depois de enviar os arquivos para um repositório público, ative GitHub Pages nas configurações do repositório, selecionando a branch principal e a pasta raiz.

> Não publique telefone, endereço residencial ou outras informações pessoais no portfólio.
