01

PROJETO DE CONCLUSÃO DE CURSO

Sistema web de gerenciamento de pontos de coleta

Sistema desenvolvido como projeto de conclusão do curso Técnico em Informática, com o objetivo de facilitar o gerenciamento de pontos de coleta e cooperados.

Principais funcionalidades

  • Cadastro e gerenciamento de pontos de coleta.
  • Gerenciamento de cooperados e vínculos.
  • Registro e consulta do histórico de coletas.
  • Gerenciamento de solicitações de benefícios.
  • Área administrativa para gerenciamento das informações.

Tecnologias utilizadas

PHP PostgreSQL HTML CSS JavaScript
